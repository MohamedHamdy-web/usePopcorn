# 🎬 Movie App (React)

A React-based movie application that allows users to search for movies using the OMDb API, view detailed movie information, rate movies, and manage a personal watched list.

This project focuses on **React fundamentals**, **state management**, **side effects**, and **user experience improvements**.

---

## 🚀 Features

- 🔍 Search movies using the OMDb API
- 📄 View detailed information about each movie
- ⭐ Rate movies with a custom star rating component
- ➕ Add movies to a watched list
- 🚫 Prevent adding the same movie twice
- ⌨️ Keyboard support (Escape key to close movie details)
- 🎮 Controller / keyboard navigation support
- ⚡ Responsive and interactive UI

---

## 🛠️ Built With

- React
- JavaScript (ES6+)
- OMDb API
- CSS
